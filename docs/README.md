## How to Browse

- Use a subject index when looking for a specific area.
- Follow related-guide links to move between connected subjects.
- Use the root learning pathway when studying from foundations through delivery.
- Treat commands and examples as starting points; adapt them to the system and risk involved.

## Navigation Responsibilities

- The root README owns the repository overview, highlighted entry points, and recommended learning order.
- This README owns the list of documentation subjects.
- Each subject README owns the guide list and suggested order within that subject.

This separation keeps the landing page concise while allowing the documentation library to grow without duplicating every guide in multiple indexes.
