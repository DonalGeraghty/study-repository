# Frameworks and Libraries

This section contains application frameworks and libraries built on top of the repository's programming-language foundations.

## Guides

- [Spring](./frameworks-spring.md) — Java dependency injection, Spring Boot, web APIs, data access, configuration, and testing.
- [React](./frameworks-react.md) — JavaScript and TypeScript components, state, application structure, accessibility, and testing.
- [Flask](./frameworks-flask.md) — Python HTTP services, request boundaries, configuration, security, and testing.
- [Vue](./frameworks-vue.md) — reactive JavaScript components, routing, application structure, and testing.
- [Express](./frameworks-express.md) — Node.js middleware, HTTP routing, service boundaries, data access, and failure handling.
- [Shiny](./frameworks-shiny.md) — reactive R web applications, data validation, visualisation, testing, and deployment.

## Suggested Use

Study the relevant language first, then capture how the framework applies that language to application architecture, delivery, and testing.
