# Programming Languages

This section contains language and runtime learning material, including both existing study guides and placeholders for experience to document later.

## Languages

- [Java](./java/README.md) — Java syntax, core APIs, concurrency, modern language features, and JVM fundamentals.
- [Kotlin](./kotlin/README.md) — null safety, functional language features, coroutines, Java interoperability, and application development.
- [Python](./python/README.md) — Python language, packaging, scripting, automation, and application development.
- [R](./r/README.md) — data transformation, statistical analysis, visualisation, and reproducible analytical work.
- [C# and .NET](./csharp/README.md) — C# language features, .NET runtime and tooling, application development, and automation.
- [JavaScript and TypeScript](./javascript-typescript/README.md) — browser and server-side JavaScript, static typing, and asynchronous programming.
- [SQL](./sql/README.md) — relational queries, data modification, transactions, indexing, and database testing.

HTML and CSS are organised separately under [Web Foundations](../web/README.md) because they structure and style web content rather than act as general-purpose programming languages.

Language-specific application ecosystems such as Android are organised under [Application Platforms](../platforms/README.md).
