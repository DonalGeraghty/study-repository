# Platform Engineering

These guides cover application packaging and container orchestration.

## Guides

1. [Docker](./docker.md) — images, containers, Dockerfiles, storage, networking, Compose, registries, and runtime security.
2. [Kubernetes](./kubernetes.md) — cluster architecture, workloads, Services, configuration, scaling, security, and operations.

Learn Docker first so images, container processes, storage, and networks are familiar before studying how Kubernetes schedules and reconciles containerised workloads.
