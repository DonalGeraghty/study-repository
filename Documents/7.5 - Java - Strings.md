# Strings

## **String vs. StringBuilder** {#string-vs-stringbuilder}

1.  **String**:
    *   **Immutable**: Once created, it cannot be changed.
    *   **String Pool**: Java saves memory by sharing identical string literals in a special "pool".
    *   **Performance**: Concatenating strings in a loop (e.g., `s += "next";`) is **slow** because it creates a new String object every single time.

2.  **StringBuilder**:
    *   **Mutable**: You can modify the contents without creating new objects.
    *   **Performance**: Much faster for heavy string manipulation or loops.
    *   **Thread-Safety**: Not thread-safe (use `StringBuffer` if you need thread-safety, though `StringBuilder` is faster for single-threaded use).

```java
// ❌ Slow: Creates 1000 objects
String s = "";
for(int i=0; i<1000; i++) s += i;

// ✅ Fast: Modifies 1 object
StringBuilder sb = new StringBuilder("Start");
for(int i=0; i<1000; i++) sb.append(i);

// Useful methods:
sb.insert(5, " - ");      // Insert text at index
sb.reverse();             // Reverse the whole sequence
sb.delete(0, 10);         // Delete a range
String finalString = sb.toString();
```
