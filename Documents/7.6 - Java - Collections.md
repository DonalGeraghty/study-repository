# Java Collections Framework {#java-collections-framework}

## **Main Ideas**

* **List**: Ordered, allows duplicates  
* **Set**: No duplicates  
* **Queue / Deque**: FIFO, LIFO, or priority-based retrieval  
* **Map**: Key-value pairs (not a Collection, but related)

---

## **List (ordered, index-based, allows duplicates)** {#list-details}

*   **ArrayList**: Resizable array. Fast access. Slower middle inserts/removals.
*   **LinkedList**: Nodes linked. Fast inserts/removals. Slow access by index.
*   **Vector**: Thread-safe ArrayList (legacy).
*   **Stack**: Legacy stack. Use `ArrayDeque` instead.

---

## **Set (unique elements, no duplicates)** {#set-details}

*   **HashSet**: Fast operations. No order guaranteed.
*   **LinkedHashSet**: Keeps insertion order.
*   **TreeSet**: Automatically sorted elements (Red-Black Tree).

---

## **Queue / Deque (FIFO / LIFO)** {#queue-details}

*   **ArrayDeque**: Recommended queue or stack replacement. Very fast.
*   **PriorityQueue**: Min-heap by default. Removes smallest first.
*   **LinkedList**: Can act as queue/deque. Slower than `ArrayDeque`.

---

## **Map (key-value lookup)** {#map-details}

*   **HashMap**: Fast lookup. No order guaranteed.
*   **LinkedHashMap**: Maintains insertion order.
*   **TreeMap**: Keys sorted automatically.
*   **ConcurrentHashMap**: Thread-safe and efficient for concurrency.

---

## **Quick Selection Guide** {#quick-selection-guide}

*   I want **fast lookups by index** → **ArrayList**  
*   I want **fast inserts/removals anywhere** → **LinkedList**  
*   I want **no duplicates** → **HashSet**  
*   I want **no duplicates + sorted** → **TreeSet**  
*   I want a **queue/stack** → **ArrayDeque**  
*   I want to always remove **smallest/largest item** → **PriorityQueue**  
*   I want **key-value storage** → **HashMap**  
*   I want key-value but **sorted keys** → **TreeMap**
