# Variables and Data Types

## **Primitive vs. Reference Variables** {#primitive-vs-reference}

In Java, variables are divided into two main categories:

1.  **Primitive Variables**:
    *   **What they are**: Basic data types built into the language (e.g., `int`, `double`, `boolean`, `char`).
    *   **Where they live**: They are stored directly on the **Stack**.
    *   **Value**: The variable holds the **actual value** (e.g., `int x = 5;` - the memory for `x` contains the number `5`).
    *   **Comparison**: Compared using `==`.

2.  **Reference Variables**:
    *   **What they are**: Variables that refer to objects (e.g., `String`, `Scanner`, `ArrayList`, or custom classes).
    *   **Where they live**: The object itself lives on the **Heap**, while the reference variable lives on the **Stack**.
    *   **Value**: The variable holds the **memory address** (reference) of where the object is located on the heap.
    *   **Comparison**: `==` compares the memory addresses (do they point to the same spot?). `.equals()` is used to compare the actual content of the objects.

## **Static Variables** {#static-variables}

The `static` keyword means that a member belongs to the **class itself**, rather than to a specific instance (object).

*   **Shared State**: Only one copy of a static variable exists, regardless of how many objects are created.
*   **Memory**: Stored in the Metaspace (Permanent Generation).

```java
class Player {
    String name;          // Instance variable: each player has their own name
    static int count = 0; // Static variable: shared by ALL players

    Player(String name) {
        this.name = name;
        count++; // Increment the shared counter every time a player is created
    }
}
```
