# The Math Class {#math-class}

The `java.lang.Math` class contains methods for performing basic numeric operations such as elementary exponential, logarithm, square root, and trigonometric functions. All methods in the `Math` class are **static**, so you don't need to create an object to use them.

## **Common Operations**

### **Basic Arithmetic**
*   **Math.abs(x)**: Returns the absolute (positive) value of x.
*   **Math.max(x, y)**: Returns the larger of two numbers.
*   **Math.min(x, y)**: Returns the smaller of two numbers.

```java
System.out.println(Math.abs(-10));    // 10
System.out.println(Math.max(20, 50)); // 50
System.out.println(Math.min(20, 50)); // 20
```

### **Rounding**
*   **Math.round(x)**: Rounds to the nearest whole number (returns `long` or `int`).
*   **Math.ceil(x)**: Rounds **up** to the nearest integer.
*   **Math.floor(x)**: Rounds **down** to the nearest integer.

```java
System.out.println(Math.round(3.5)); // 4
System.out.println(Math.ceil(3.1));  // 4.0
System.out.println(Math.floor(3.9)); // 3.0
```

### **Exponents and Roots**
*   **Math.pow(base, exponent)**: Returns base raised to the power of exponent.
*   **Math.sqrt(x)**: Returns the square root of x.
*   **Math.cbrt(x)**: Returns the cube root of x.

```java
System.out.println(Math.pow(2, 3));  // 8.0
System.out.println(Math.sqrt(16));   // 4.0
```

### **Random Numbers**
*   **Math.random()**: Returns a `double` between `0.0` (inclusive) and `1.0` (exclusive).

```java
// Generate a random integer between 1 and 10
int randomNum = (int)(Math.random() * 10) + 1;
```

### **Constants**
*   **Math.PI**: The ratio of the circumference of a circle to its diameter (~3.14159).
*   **Math.E**: The base of natural logarithms (~2.718).
